# GWU Technologies

The official website for **GWU Technologies** — an AI company building **AI Inspector**, a human-in-the-loop machine vision platform for industrial quality inspection. Manufacturers use it to catch defects on production lines: a camera watches parts move down the conveyor, an AI model flags each one **OK** or **NOK** (not okay) in real time, and an operator stays in the loop to confirm and continuously retrain the model.

The site also covers GWU's machine vision accessories, software development and AI integration services, virtual education programs, and company news.
